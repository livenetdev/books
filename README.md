# Books

The debloated reader that just works. Any file format, intuitive controls, and actually pleasant to use. For macOS.

**[Download Books for Mac](https://github.com/livenetdev/books/releases/latest/download/Books.dmg)**
· macOS 14 or later · free, from Livenet

## Install

1. Open `Books.dmg` and drag Books into Applications.
2. Open Books from Applications.

If macOS says it can't verify the developer, open **System Settings › Privacy & Security** and click **Open Anyway**.

## Updating

Download again from the link above. Only the newest version is kept here.
